# 로봇 통합 실행본

노트북 `server.py`와 Raspberry Pi `pi_client/client.py`로 탐색부터 불 접근·정렬·각도 조절·발사까지 연결합니다.

**사람 > 불 > 좌우 탐색** 순서이며, 모든 서보 전원·PWM이 연결된 구성을 전제로 합니다.

## 동작 순서

탐색 → 불 중앙 추적 → 200cm 이하 도착 확인 → 최종 정렬·위치 저장 → 현재값 재확인 → 13번 각도 조절 → 14번 3초 구동 → 정지 유지.

- 보행 폭 79%, 장애물 정지 50cm
- 13번 수평 PWM 280, 각도 +20° 보정
- 14번 구동 PWM 492 / 3초, 정지 PWM 301
- 동일 실행에서 한 번 발사, 종료 시 다리 PWM 해제
- 사람 발견 시 정지·경고음·화면·자동 로그
- 상단 UI 및 불 중점 표시, 카메라 원본·UI 포함 영상 동시 저장

이 폴더 전체를 내려받아 사용하세요. 노트북은 `setup_pc.cmd`로 설치한 뒤 `run_server.cmd`로 실행합니다. Pi에는 `pi_client`의 내용물을 `/home/pi/Downloads/last_combined`로 복사합니다.

YOLO 모델은 `models/yolo_fire_person.pt`에 포함되어 있습니다. 영상·로그는 노트북의 `recordings/combined/`에 저장됩니다.

`start` 또는 SPACE로 시작, `stop` 또는 S로 정지, Q로 종료합니다. 발사 출력을 허용할 때 Pi 실행 명령에 `--execute --arm`을 사용합니다.

## 코드 검사

로컬 검사 16개, 하드웨어 입출력을 대체한 연결 검사에서 자동 전환·14번 3초 구동·연속 녹화를 확인했습니다. 파일 해시는 `MANIFEST.json`에 있습니다.
